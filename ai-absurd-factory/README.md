# Контент-завод «Нейрон Палыч»

Абсурдный юмор про ИИ для Reels, TikTok и Telegram-канала. Почему выбрана эта ниша и как устроена воронка
в Telegram, описано в [STRATEGY.md](STRATEGY.md). Герои, тон и ограничения собраны в [brand/bible.md](brand/bible.md).

## Как это работает

```
Автор (Claude) ── пишет 6 постов и 2 сценария роликов
      │
      ▼
Критик №1 и критик №2 (независимые вызовы, видят только готовый текст и библию)
      │  итог = среднее; публикуем при итоге ≥ 8, каждом критерии ≥ 6 и safe у обоих
      ├── не прошло → автор переписывает по правкам (до 2 раз) → снова критики
      ├── не прошло после 2 правок → data/rejected.jsonl (идея больше не повторится)
      ▼
Посты  → data/post_queue.jsonl → Telegram-канал 3 раза в день (лучшие по оценке первыми)
Ролики → data/reels/*.json (сценарий + промпт для видеомодели + подпись с CTA + пост «чем кончилось»)
```

Расписание задаёт GitHub Actions ([`.github/workflows/neyron-palych.yml`](../.github/workflows/neyron-palych.yml)):
запуск в 09:07, 14:07 и 20:07 по Москве. Если в очереди меньше 3 одобренных постов, сначала пишется новая партия.
После каждого запуска очередь и история коммитятся обратно в репозиторий.

## Запуск (один раз)

1. **Канал и бот.** Создайте канал в Telegram, а через [@BotFather](https://t.me/BotFather) создайте бота
   и добавьте его в канал администратором с правом публиковать сообщения.
   Чтобы под постами работали комментарии, привяжите к каналу группу обсуждений.
2. **Секреты в GitHub** (Settings → Secrets and variables → Actions):
   - секрет `ANTHROPIC_API_KEY`: ключ из [console.anthropic.com](https://console.anthropic.com);
   - секрет `TELEGRAM_BOT_TOKEN`: токен от BotFather;
   - переменная `TELEGRAM_CHANNEL`: `@имя_канала`;
   - необязательно: `APPROVE_THRESHOLD` (по умолчанию 8) и `CRITIC_VOTES` (по умолчанию 2).
3. **Ветка по умолчанию.** GitHub запускает расписание только из ветки по умолчанию, поэтому эту ветку нужно влить в `master`.
4. **Проверка.** Actions → «Нейрон Палыч — контент-завод» → Run workflow с `dry_run`:
   конвейер напишет и проверит посты, покажет в логе, что опубликовал бы, но в канал ничего не отправит.

Локально:
```bash
cd ai-absurd-factory
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
python -m factory.run --dry-run tick           # полный цикл без публикации
python -m factory.run generate reels 2         # только сценарии роликов
python -m factory.run status                   # очередь
python -m pytest -q tests                      # тесты без сети
```

## Ролики: что автоматизировано, а что нет

| Шаг | Статус |
|---|---|
| Сценарий, хук, промпт для видеомодели, подпись с кодовым словом, пост «чем кончилось» | Автоматически, с проверкой критиками |
| Генерация видео | Через Higgsfield (Seedance 2.5) в сессии Claude. Ролик на 12 секунд стоит около 84 кредитов |
| Публикация в TikTok | Через Higgsfield, но сначала нужно подключить аккаунт TikTok. Финальную отправку TikTok требует подтверждать в форме, поэтому один клик остаётся за вами |
| Публикация в Instagram Reels | Нужен бизнес-аккаунт и токен Meta Graph API. Пока делается вручную |
| Кодовое слово в комментах → ссылка в директ | Сервис автоответа для Instagram (ManyChat или аналог), настраивается один раз |

## Первый прогон (26.10.2026)

Автор написал 7 постов и 2 сценария, а свежий критик каждый раз оценивал их без доступа к прошлым оценкам.
Было три раунда правок, полный лог лежит в [`data/first-run/`](data/first-run/).

| Раунд | Лучшая оценка | Прошло порог 8 |
|---|---|---|
| 1 | 7.0 | 0 из 9 |
| 2 (после правок) | 7.7 | 0 из 9 |
| 3 (4 лучших) | 7.6 | 0 из 4 |

Ничего не опубликовано: фильтр работает так, как задумано. Самые частые замечания критика вошли в правила библии:
первая строка должна быть хуком, в каждом посте нужен CTA, в кадре не должно быть кириллицы,
в ролике не больше 1–2 кадров и 3 событий. Разброс оценок между критиками (7.7 и 6.3 за один и тот же пост)
показал, что одной оценке доверять нельзя, поэтому теперь итог складывается из двух независимых критиков.
